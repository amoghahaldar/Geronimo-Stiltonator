# Geronimo Stiltonator

This web application allows users to reconfigure standard text into the nostalgic typography of their childhood, automatically emphasizing and styling key words just like a classic Geronimo Stilton novel. 

Developed collaboratively during a 24-hour hackathon, this project combines natural language processing with web fundamentals to create an engaging, interactive reading experience. 

### Features
* **Dynamic Typography:** Automatically identifies parts of speech and applies unique font stylings, colors, and sizes to descriptive words.
* **Interactive Teaching Mode:** Includes a dedicated mode designed to help children practice and understand English grammar fundamentals visually.

### Tech Stack
* **Backend:** Natural Language Processing (NLP)
* **Frontend:** HTML, CSS

### About the Project
This application was built from scratch in under 24 hours as a team hackathon submission. The primary technical challenge involved leveraging NLP to accurately parse sentences and isolate target vocabulary for dynamic CSS rendering without relying on external API services.
